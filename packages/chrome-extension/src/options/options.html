TaskPilot Context Capture

Sends visited URLs + page titles to your local TaskPilot app (http://127.0.0.1:7847). Never leaves your machine.

On macOS/Linux: cat ~/.taskpilot/api-token. On Windows: Get-Content $env:USERPROFILE\.taskpilot\api-token. Stored only in this browser's extension storage.

Uncheck to pause captures without uninstalling.

Change this only if TaskPilot is listening on a non-default host.

Default .* matches everything HTTPS/HTTP.

Defaults include banks, login pages, password managers.
